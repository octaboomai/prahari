What is Prahari?

Prahari is a specialized compliance automation platform designed for Small and Medium Enterprises (SMEs) in India. It transforms incident detection into correctly-timed, correctly-formatted regulatory filings for two critical regulators:

🇮🇳 CERT-In

6 Hours
Initial incident notification deadline

📋 DPDP Board

72 Hours
Detailed breach report deadline

Prahari handles the dual-clock compliance workflow—the one component nobody else is selling to the Indian SME segment.

✨ Core Features

📝 Incident Intake

Modeled on CERT-In's official Incident Reporting Form with all DPDP breach-notification fields built in.

⏱️ Dual-Clock Engine

Computes both CERT-In (6h) and DPDP (72h) deadlines from a single detection timestamp with urgency banding.

📊 Live Dashboard

Twin countdown clocks ticking client-side in real-time with color-shifts as deadlines approach.

📄 Report Generation

Renders both CERT-In and DPDP Board reports (initial + detailed) as HTML or downloadable text.

📋 Audit Trail

Mark-as-reported timestamps prove on-time vs. late filing for regulatory compliance verification.

🔍 Retention Tracking

Tracks log source monitoring duration against 365-day window (satisfies both CERT-In and DPDP requirements).

🎯 What's Built | What's Not

✅ Built Here

  • Dual-clock compliance engine (core IP)
  • Incident intake form & report generation
  • Live countdown dashboard
  • Audit trail for filing verification
  • Log source retention tracking

❌ Out of Scope (Integrate Instead)

Prahari deliberately does NOT build:
  • Dark-web/credential monitoring — Integrate via Flare's TEM platform
  • External attack-surface scanning — Use Shodan or Censys API
  • Multi-tenancy — Schema is single-org; designed for easy migration
  • Real multi-user auth — HTTP Basic Auth is sufficient for single org

🚀 Getting Started

Local Development

Run Prahari on your local machine:

python3 -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
export PRAHARI_USER=yourname
export PRAHARI_PASSWORD=yourpassword
uvicorn app.main:app --reload --port 8000

Then open http://localhost:8000 and log in with your credentials.

Deploy to Production

Recommended: Railway (railway.com)

1. Push to GitHub — Create a new GitHub repo with this code
2. Connect Railway — New Project → Deploy from GitHub repo
3. Set Environment Variables
  • PRAHARI_USER — Your username
  • PRAHARI_PASSWORD — A real password
  • PRAHARI_DB_PATH — `/data/prahari.db`
4. Attach Volume — Mount `/data` volume for persistent SQLite storage
5. Go Live — Railway provides `*.up.railway.app` URL immediately

Cost: ~$5/month on Railway Hobby plan after free trial

🔐 Security & Auth

Every route is gated behind HTTP Basic Auth. Set these environment variables before production deployment:

PRAHARI_USER=yourname
PRAHARI_PASSWORD=something-real-not-changeme
⚠️ Default Credentials
Locally falls back to admin / changeme with console warning. Never use defaults in production.
